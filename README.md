# Eledralabs Landing Page

Precision-engineered Web and AI workflows landing page built with Next.js and Tailwind CSS.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Icons:** Material Symbols

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Pages

- `/` — Home with animated workflow canvas
- `/solutions` — Web Solutions & AI Automation
- `/industries` — Industry-specific solutions
- `/contact` — Contact form & scheduling

## Features

- Animated workflow canvas hero
- Scroll reveal animations
- Interactive calendar
- Responsive navigation with hide/show on scroll
- Material Design 3 inspired color system
